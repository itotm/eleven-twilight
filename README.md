# ElevenTwilight

Windows 11 Style icon theme based on the excellent https://github.com/mjkim0727/Eleven-icon-theme

## Changes

- reworked symbolic icons to be used on themes like Breeze Twilight, with light apps and dark shell
- added missing icons from Cobalt
- made defaults smaller
- removed weather symbolic icons (to always be in colored version)

## ElevenTwilightColoredToolbars

Overlay theme with colored Windows 11 style toolbar icons, everything else
inherited from ElevenTwilight.

## Development

Theme versions live in `VERSIONS`.

```
python3 tools/build.py [--install]   # regenerate the colored theme
tools/package.sh                     # release archives in dist/
```
